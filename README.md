# Proyecto PokeAPI - Clase 1

Este proyecto es una introducción a **React + TypeScript**, enfocado en el consumo de APIs externas, tipado fuerte y buenas prácticas de seguridad.

## Requerimientos Cumplidos
- **RT01-RT03**: Configuración de entorno con Vite y Yarn.
- **RT04**: Implementación de políticas de seguridad en `.npmrc`.
- **RT05**: Consumo de la PokéAPI (primeros 20 Pokémon) usando `fetch`.
- **RT06**: Creación de interfaces de TypeScript para el modelo de datos.
- **RT07**: Documentación del proceso en este README.
- **Extra**: Estilos condicionales para resaltar a mi Pokémon favorito.

## Tecnologías Usadas
* React 18
* TypeScript
* Vite
* CSS Dinámico

## Instalación y Ejecución
1. Clonar el repositorio.
2. Ejecutar `yarn install` para instalar dependencias.
3. Ejecutar `yarn dev` para iniciar el servidor de desarrollo.

# Proyecto PokeAPI - Clase 2

Enfoque en la navegación dinámica, componentes reutilizables y manejo de estados.

## Requerimientos Cumplidos 
- **RT03**: Creación de componentes reutilizables (`PokemonCard`) para evitar duplicidad de código.
- **RT08**: Organización profesional del proyecto mediante carpetas específicas para `pages`, `components` y `services`.
- **RF02**: Implementación de una vista de detalle funcional que muestra:
  - Imagen oficial.
  - Peso y Altura.
  - Habilidades y Tipos.
  - Estadísticas base (HP, Attack, Defense, etc.).
- **Navegación**: Uso de `react-router-dom` para gestionar rutas dinámicas (`/pokemon/:name`) y navegación entre pantallas.
- **Git (RT06)**: Historial de commits ordenado y descriptivo del progreso.

## Tecnologías Usadas
* React 18
* TypeScript
* Vite
* React Router DOM
* CSS Dinámico

## Instalación y Ejecución
1. Clonar el repositorio.
2. Ejecutar `yarn install` para instalar las dependencias (incluyendo la nueva librería de navegación).
3. Ejecutar `yarn dev` para iniciar el servidor de desarrollo.
